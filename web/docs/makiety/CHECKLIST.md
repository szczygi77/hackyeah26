3. `03-karta.png` — `/karta/telefon-na-dzien-dobry`
4. `04-sprawdz.png` — kontrola warunków
5. `05-zgodnosc.png` — Macie / Brakuje / Do sprawdzenia
6. `06-middleman.png` — szkic planu
7. `07-pomysl.png` — fiszka + kanwa
8. `08-zgloszenie.png` — status + wątek
9. `09-admin.png` — kolejka + ranking luk
10. `10-mobile-home.png` — home w 375px

Aplikacja jest klikalna end-to-end — makiety = zrzuty działającego UI.
