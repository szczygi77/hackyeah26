# Audyt potrzeb — HubMI / Szczep

Źródła: oficjalna diagnoza wyzwania ROPS (brief HubMI), [rops.krakow.pl](https://rops.krakow.pl/) (aktualności IX–X 2026), Mapa Wyzwań Społecznych, taxonomia Biblioteki (9 kategorii).

## 1. Potrzeby systemowe (instytucja)

| Potrzeba | Dowód / sygnał | Odpowiedź w Szczepie |
|----------|----------------|----------------------|
| Odkrywalność ~200 innowacji | Portfolio inkubatora mało znane poza kontekstem lokalnym | Marketplace `/`, `/zasobnik`, 9 kategorii |
| Skalowanie oddolnych mikro-rozwiązań | NGO/CUS bez narzędzi rozwoju | `/pomysl` (fiszka, Social Canvas, nabór) |
| Łączenie potrzeb z wiedzą i rozwiązaniami | Wizja Hubu jako jednej przestrzeni | Matchmaking → `/wyniki` → `/sprawdź` → Middleman |
| Widoczność luk i trendów | ROPS jako moderator ekosystemu | `/admin` (kolejka, luki, trendy) |
| Testowanie przed wdrożeniem | Inkubacja = test + ewaluacja | `/tester`, wątki, partnerstwa |

## 4. Persona → job-to-be-done

1. **Pracownik CUS / GOPS** — „mam problem w gminie; co już działa i czego mi brakuje?”  
2. **NGO / PES** — „mam mikro-rozwiązanie; jak je opisać i znaleźć partnera / nabór?”  
3. **Mieszkaniec / opiekun** — „szukam wsparcia bez żargonu”  
4. **ROPS / Hub** — „gdzie są luki, kto testuje, co moderować”  
5. **Ekspert / mentor** — „chcę dołączyć do wątku wdrożenia”

## 5. Kryteria sukcesu audytu (demo)

- Jury w 30 s słyszy: ROPS ma wiedzę i portfolio → oddolne pomysły nie skalują się → Szczep łączy je w Hubie.  
- Każda z 5 potrzeb systemowych ma klikalną ścieżkę I–VII.  
- Karty inspirowane ROPS są oznaczone jako syntetyczne / poglądowe.
